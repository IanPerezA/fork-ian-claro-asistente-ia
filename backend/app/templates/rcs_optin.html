Política de Opt-In RCS – Claria

Claria solo envía mensajes RCS a usuarios que han otorgado consentimiento explícito previo (opt-in).

¿Cómo se obtiene el consentimiento?

  • El usuario inicia voluntariamente una conversación con Claria.
  • El usuario acepta recibir mensajes mediante una acción explícita (por ejemplo, un checkbox o aviso visible).
  • El usuario escanea un código QR que abre una conversación RCS.

Información al usuario

Antes de otorgar el consentimiento, el usuario es informado de:

  • El tipo de mensajes que recibirá.
  • Que los mensajes se enviarán mediante RCS.
  • La posibilidad de cancelar en cualquier momento.

Claria no utiliza listas de terceros ni envía mensajes no solicitados.
